Batch vs. normal API calls

Normal: send a request and wait for the answer now. Batch: queue many separate requests and collect their answers later. Batch API processing costs 50% less at both providers, but is asynchronous: OpenAI sets a 24-hour completion window; Anthropic says most batches finish within an hour, with a 24-hour limit. Use it for overnight summaries, bulk classification, or model evaluations—not live chat or work that needs an immediate answer. You submit it through an API script or app; it does not discount Codex or Claude subscription usage.
